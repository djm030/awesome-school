# AI 코딩 보조 도구 사용 내역

## 쓴 도구

- **Claude Code** (모델: Claude Opus 5.5), Orca 터미널에서 실행
- Claude Code 안에서 쓴 기능: 하위 에이전트(웹 조사), Orca 내장 브라우저 자동화(화면 확인), AWS CLI·Docker·uv 실행

## 왜 썼나

마감까지 약 64시간 안에 설계 논의, 구현, 화면 확인, AWS 배포, 문서까지 끝내야 했습니다. 손이 많이 가는 일(조사, 마크업, 스크립트, 반복 확인)은 AI에 맡기고, 저는 **요구사항을 어떻게 해석할지 결정하고 결과를 검토하는 데** 시간을 썼습니다.

## 단계별 사용

| 단계 | AI가 한 일 | 제가 한 일 |
|---|---|---|
| 요구사항 정리 | 과제 문구에서 정해야 할 결정을 질문으로 뽑아 라운드마다 추천안과 함께 제시 (4라운드, 25문항) | 각 질문에 답하고, 이해가 안 되는 질문은 더 자세히 설명하게 함 |
| 회사·콘텐츠 조사 | 사람인 공고와 hero-school.net을 읽고 기술 스택, 사업 구조(학교로 찾아가는 B2B 수업), 과정별 커리큘럼 원문을 정리 | 어떤 과정을 쓸지 고름 |
| 구현 | Django 모델·API·페이지·SCSS·JS, 메일·시트 기능, 테스트 작성 | 화면 문구와 동작을 검토 |
| 확인 | Django 테스트 10개, 내장 브라우저로 데스크톱·모바일(390px) 화면과 신청·우편번호 검색·관리자 화면 동작 확인 | 결과 확인 |
| 배포 | AWS CLI로 EC2·RDS 생성, Docker 배포, cron 등록, 운영 서버 점검 | 비용이 드는 실제 배포 여부 결정 |
| 문서 | README, AWS 구성, 용어집(CONTEXT.md), ADR 초안 | 내용 검토 |

## 제가 정한 것과 AI 추천이 달랐던 곳

AI는 매 질문마다 추천안을 냈고, 대부분은 받아들였지만 아래는 제가 다르게 정했습니다.

| 질문 | AI 추천 | 제 결정 | 이유 |
|---|---|---|---|
| 우대 과제 범위 | 시트 내보내기는 시간이 남으면 | 우대 4개 모두 | 전부 해 보는 것이 목표 |
| AWS | 마감까지 3일이 안 남으면 문서만 | 실제 배포 | 리뷰어가 링크로 바로 확인할 수 있게 |
| 스타일 | 순수 CSS | SCSS | 회사 기술 스택(SCSS/Sass)에 맞춤 |
| 중복 신청 | 진행 중인 신청이 있으면 막기 | 받고 관리자에게 표시 | 담당자가 판단하도록 |
| 개인정보 동의 | 동의 시각까지 저장 | 체크박스만 | 실제 운영 전제가 아님 |
| 시트 내보내기 | 버튼으로 덮어쓰기 | 버튼 + 매일 자동 | 영향을 설명받은 뒤 결정 |

AI의 조사와 질문으로 처음 알게 되어 반영한 것도 있습니다.

- 히어로스쿨은 학교로 찾아가는 수업이 주력이라, **신청자를 기관 담당자로, 주소를 수업 장소로** 해석했습니다 ([ADR 0001](adr/0001-applicant-is-organization-staff.md)).
- 연락 가능 **시간대**를 받기로 하자, AI가 "전화할 번호가 없다"는 모순을 짚어 **연락처** 필드를 추가했습니다.

## AI가 틀렸다가 바로잡은 것

| 문제 | 원인 | 조치 |
|---|---|---|
| AWS EC2 생성 실패 | user-data 스크립트의 한글 주석을 Windows용 AWS CLI가 읽지 못함 | 주석을 영어로 바꾸고, 이미 만든 보안 그룹·RDS를 그대로 써서 나머지만 이어서 생성 (잃어버린 DB 비밀번호는 재설정) |
| 로컬 서버 500 오류 | `.env`의 빈 `DJANGO_SECRET_KEY=`가 기본값을 덮어씀 | 빈 값도 기본값으로 처리 |
| 첫 화면 리다이렉트 | 잘라낸 쿼리셋에 `get_object_or_404` 사용 | `first()`로 수정 |
| 콘솔 메일 출력 실패 | Windows 콘솔(cp949)이 `–` 문자를 출력하지 못함 (로컬만 해당) | UTF-8 모드로 실행. 이 과정에서 실패한 메일이 다음 실행에 재발송되는지도 확인 |

## 검증 원칙

- AI가 "됐다"고 한 기능은 테스트나 실제 화면·응답으로 확인했습니다. 확인 방법은 README의 테스트 항목과 위 표에 적었습니다.
- 비밀값(DB 비밀번호, SECRET_KEY, 관리자 비밀번호)은 스크립트가 무작위로 만들어 `secrets/`에만 두고, 대화나 저장소에는 남기지 않았습니다.

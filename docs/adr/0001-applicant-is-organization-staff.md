# 신청자는 개인이 아니라 기관 담당자다

과제 폼(이름·이메일·주소·연락 가능 날짜)은 개인 수강 문의로도 읽히지만, 히어로스쿨의 실제 사업은 히어로코치가 학교·기관을 찾아가는 B2B 수업이다. 그래서 신청자를 기관을 대표하는 담당자(주로 교사)로 정의하고, 주소는 수업이 열리는 기관의 주소로, 기관명을 필수 항목으로 추가했다. 개인 수강 모델로 바꾸려면 폼 문구·안내 메일·관리자 화면의 기관 기준 정렬을 모두 고쳐야 한다.

## Considered Options

- 개인(학생·학부모) 수강 문의: 과제 문구에 더 가깝지만 "왜 주소를 받는가"에 답이 없고, 회사의 실제 운영 흐름(hero-school.net `/apply/`의 기관 단위 견적 신청)과 어긋난다.
